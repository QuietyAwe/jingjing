### P8-1 巩固流（59/59）

- 提取范围 = 游标之后 ~ 滑动窗口之前（快照逐条与消息内容核对）；
- 一次巩固最多 5 条片段，超额丢弃且不建事件；
- 挂靠：`target_event_index` 有效→挂旧事件；无效→回落默认事件；`new_event_text` 先过 `findSimilarEvent`（「玩快艇骰子对战」并入「和AI玩快艇骰子」，不新建重复事件）；全空→挂「日常闲聊」；
- 归一化：`priority=99 → 5`、gist 缺失 → `summary.slice(0,24)`、keywords 逗号落库；
- Merge：likes 去重、`current_stressors` 只留最近 5 条、traits 12 / goals 10 / social·tasks 30、social 按姓名 upsert、completed/cancelled 任务自动移除；
- 游标：按消息 id 锚定；**删掉游标之前的旧消息后中间对话不丢**（msg09 仍被提取）；锚点被删按时间戳兜底、不重复提取老记忆；旧下标游标（`last_consolidated_index`）就地迁移为 id 锚点；
- 窗口全是游戏回合：跳过 LLM 但推进游标、清零计数（不空转）；
- LLM 失败（非 JSON / 缺 new_info / 无片段）：返回 false、不推进游标、**保留计数下次重试**、锁释放。

### P8-2 灵光一闪 + Token 截断（26 + 28 = 54/54）

- bigram 分词不漏真实词、超长输入 16 词均匀抽样（句尾可召回）、`scoreOverlap` 按不同关键词计数；
- 检索命中带出关联片段、命中刷新权重 100 与 last_accessed；Top N 命中在前、氛围按实时权重限量 5（回归确认：`active_weight` 恒 100 时不会退化成「最早创建的事件」）；
- 默认事件排除在命中之外、仅无命中时兜底注入且只带最近 3 条；
- 灵光一闪：概率 0 不触发 / 1 必触发；优先挑与输入弱关联的冷记忆（含「海浪」的冷事件，绝不选无关冷记忆）；无弱关联退化为随机冷记忆；注入「事件标题 + 一句 gist」；
- 记忆分层：命中事件最多 4 条片段（最早 1 + 最近 3）；live≥40 给 summary、live<40 只留 gist；priority≥7 阈值×0.6、≤3 阈值×1.5（同一权重 45：P7 给全文、P3 只留一句）；gist 缺失回退 summary 前 24 字；
- 截断顺序（41 档预算扫描 + 定点断言）：**先删灵光一闪 → 低权重块先降级为一句话 → 按权重升序整块删 → 最后丢最旧历史（至少保留最后一轮）**；任何截断发生时灵光一闪必已删；开始删块后存活块均已降级；丢历史只在记忆块删完后；
- 截断不污染输入数组；system 角色消息转 user 注记；最后两条用户消息带时间戳。

### P8-3 空库冷启动（26/26）

- 空库：`buildColdStartPrompt` = 系统人设 + 引导模板，`[user]` → 「用户」，无状态/记忆区；
- `buildChatContext` 空库走冷启动分支（isColdStart、memoryCount=0）；
- 有昵称后 `[user]` → 昵称；空画像空字段整行隐藏（喜欢/讨厌/社交/性格/压力/沟通/愿望/待办）、空段落标题清理、占位符回退（你｜神秘职业｜未知地方）；
- 所有分支无 `undefined` / `__EMPTY__` / 未替换占位符泄漏；
- 消息发送顺序核对：**人设 → 状态区 → 游戏区 → 记忆区 → 历史 → 游戏回合指令（置末）**，与 CODEBUDDY.md 声明一致。

## 四、发现（均为轻微，未改代码，留给白天决策）

1. **记忆区事件数可为「上限 + 1」**：`src/memory/retrieval.ts` 无命中补默认事件时，`topEvents.unshift(...)` 发生在 `.slice(0, context_active_events_limit)` 之后（约 188 行）。默认事件额外占一位。建议：要么接受（默认事件不算氛围位），要么把 unshift 放进 limit 内，或在 CODEBUDDY.md 注明。
2. **「恢复默认」按钮热区偏小**：`app/(tabs)/settings.tsx` 约 1279 行，`onPress={handleResetConfig}` 挂在内层 `Text` 而非 `TouchableOpacity`，只有点到文字才生效。P9-1 收尾顺手可修。
3. 本轮曾出现 3 次失败断言，定位后均为**用例自身问题**（假 SQLite 返回字段名 `lastInsertRowid`、断言标记与 `slice(0,24)` 兜底撞车、单调方向写反），产品行为全部正确；已修正用例后复跑全绿。
